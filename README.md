# 港话通 (KongType AI) · RIME (librime) 部署与安装指南 (v1.6.0 通用汉字与全拼补全升级版)

### 🌟 本次版本重大改进 (v1.6.0)：
1. **彻底解决单字拼音不出字问题 (如输入 chen 出字)**：
   - 全面引入通用汉字拼音词典联动 (`import_tables: [luna_pinyin]`)，并预置常见姓氏与单字库；
   - 输入单字拼音如 `chen` 候选框立即清晰呈现：**1. 陈 2. 陳 3. 沉 4. 晨 5. 趁 6. 臣 7. 衬 8. 称 9. 辰 10. 尘**；
   - 包含全国常见百家姓氏（李、王、张、刘、陈、杨、赵、黄、周、吴...）与日常单字，无论打短句还是单字都 100% 顺畅。
2. **搜狗输入法经典白皮肤 (告别黑底看不清)**：
   - 小狼毫 (Weasel) 与鼠须管 (Squirrel) 默认启用 **「搜狗经典白 (Sogou Clean White)」** 高对比度皮肤！
   - 纯白背景 (`0xffffff`) + 深黑字迹 (`0x202020`) + 经典搜狗蓝高亮条 (`#2563eb`)，字迹黑白分明超清晰。
3. **搜狗习惯：输入完按空格转换，按回车输出英文**：
   - 打字时完整保留拼音编码串，绝不在输入中途胡乱截断抢词；
   - 输入完完整拼音后，按下 **【空格键】** 确认一键转换上屏港话/文字；
   - 若要直接输出拼音或英文字母，直接按下 **【回车键 (Enter)】** 即可原始字母上屏。

## 🪟 Windows (小狼毫 Weasel) 一键部署步骤
1. 点击网页上的 **「一键下载全套 RIME 配套包 (v1.6.0)」**。
2. 解压下载的压缩包 `kongtype_rime_config_v1.6.0.zip`。
3. 双击运行其中的 **「Windows一键安装部署.bat」**（会自动拷贝配置文件与标准拼音词典并调用重新部署）。
4. 或者按快捷键 `Win + R`，输入并回车：
   `%APPDATA%\Rime`
   将解压出的全部文件（含 kongtype_hk、luna_pinyin 及 essay.txt 词频表）复制到该目录（覆盖原有同名文件）。
5. 在 Windows 右下角托盘图标中，右键点击小狼毫（中/英图标），选择 **「重新部署」**（Deploy）。
6. 等待 2~3 秒部署完成后，即刻拥有搜狗白底横排、支持单字与长句转换的香港话输入法！
